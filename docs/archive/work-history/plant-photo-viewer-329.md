1. 식물 상세에서 기존 사진이 있을 때 확대 보기를 제공한다. 사진이 없으면 현재 빈 이미지를 표시하고 확대 버튼을 숨긴다.
2. 확대 화면의 원본 비율, 핀치 확대, 닫기와 이미지 오류 표시를 위젯 테스트로 확인한다.
3. FVM 포맷, 정적 분석, 전체 테스트 및 diff 검사를 실행한다.

- `2553644`에서 확대 화면과 위젯 테스트를 구현했다. 사진이 없는 경우, 원본 비율, 핀치 확대, 닫기·뒤로가기 및 이미지 오류 표시를 확인했다.

### 식물 상세 사진 조회 실패 재시도

사진이 등록되지 않은 식물에는 기존 빈 이미지를 표시한다. 사진이 있지만 불러오기에 실패하면 상세 대표 사진과 확대 화면에서 오류 문구와 재시도 버튼을 표시한다.

1. 상세 사진과 확대 화면이 같은 사진을 다시 요청하도록 연결한다. 재시도 중에는 진행 표시를 보여 준다.
2. 사진이 없는 경우, 최초 실패, 재시도 중, 복구 이후 확대 동작을 위젯 테스트로 확인한다.
3. FVM 포맷, 정적 분석, 전체 테스트 및 diff 검사를 실행한다.

상세 화면과 확대 화면에 모의 HTTP 503을 적용하고, 같은 URL을 한 번만 다시 요청해 복구하는 것을 확인했다. FVM 포맷과 정적 분석, 식물 상세 관련 테스트 17개와 전체 테스트 886개가 통과했다. 기존 Linux 전용 골든 테스트 1개는 건너뛰었다.
