# 회원정보 수정 아이콘 #337

마이페이지 수정 버튼에 [Figma 벡터 `170:13291`](https://www.figma.com/design/aczb7WXctn1R3YFjmkgtXf/Common-Plant?node-id=170-13291)를 적용한다. SVG의 고유 크기와 색상을 사용하고, 기존 버튼 터치 영역과 회원 정보 수정 화면 진입을 유지한다.

SVG 렌더링 검사와 기존 위젯 테스트를 실행한다. Android 에뮬레이터에서 아이콘의 비율과 수정 화면 이동을 확인한다.

## 구현 및 검증

- `3938f4e`에서 적용 범위를 기록했고, `e7bc697`에서 Figma 원본 SVG를 마이페이지 수정 버튼에 연결했다.
- `xmllint` 검사와 원본 파일 비교, FVM 포맷·분석, Flutter 테스트 892개가 통과했다. 기존 테스트 1개는 제외됐다.
- Android 에뮬레이터에서 Figma의 회색과 아이콘 비율을 확인했다. 수정 아이콘을 누르면 회원 정보 수정 화면이 열리고, 뒤로 가면 마이페이지로 돌아온다.
