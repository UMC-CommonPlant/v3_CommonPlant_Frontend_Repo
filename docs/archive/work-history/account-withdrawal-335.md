# 설정 회원탈퇴 화면 #335

[회원탈퇴 시안](https://www.figma.com/design/aczb7WXctn1R3YFjmkgtXf/Common-Plant?node-id=170-13129)의 전용 화면을 설정의 회원탈퇴 항목에서 연다.

- 회원탈퇴 유의사항을 확인하면 삭제 버튼을 활성화한다.
- 기존 `DELETE /users`와 인증 세션 정리를 재사용한다. 처리 중 중복 제출을 막고 실패 시 같은 화면에서 다시 시도할 수 있다.
- 현재 API에서 확인할 수 있는 계정 이용 종료를 안내한다.
- 기존 설정 로그아웃은 확인창을 유지한다.

설정 진입과 뒤로 가기, 버튼 상태, 실패 후 재시도, 성공 후 로그인 이동을 테스트한다. 375×812와 작은 화면의 레이아웃을 확인하고 에뮬레이터에서 시안과 비교한다.

## 구현과 검증

| 커밋 | 변경 |
| --- | --- |
| `149b7ec` | 요구사항과 검증 범위 기록 |
| `ca233c5` | 전용 화면, Figma 자산, 설정 경로, API 동선 테스트 적용 |

- `fvm dart format --output=none --set-exit-if-changed .`, `fvm flutter analyze --no-pub`, `git diff --check` 통과.
- `fvm flutter test --no-pub`는 898개 통과, 기존 건너뜀 1개. 세 가지 화면 크기에서 확인 토글과 뒤로 가기를 검증했고, 테스트 응답으로 중복 요청 방지와 실패 후 재시도, 성공 후 로그인 이동을 확인했다.
- Android 에뮬레이터에서 마이 → 설정 → 회원탈퇴 경로와 확인 전후 버튼 상태를 확인했다. 계정 삭제 요청은 테스트 응답으로 검증했다.
- 장소와 메모의 영구 삭제 여부는 현재 API에서 확인되지 않아, 화면은 탈퇴 후 계정 접근 종료를 안내한다.
