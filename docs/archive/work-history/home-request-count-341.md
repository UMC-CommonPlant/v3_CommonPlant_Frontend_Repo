# 홈 장소 요청 버튼 표시 #341

홈 My place에서 장소 요청 조회가 0건으로 끝나면 요청 버튼을 숨긴다. 양수 결과에는 요청 수를 표시하고 기존 요청 목록으로 이동한다. 조회 중과 오류 상태는 각각 진행 표시와 재시도 버튼으로 표시한다.

홈 위젯 테스트에서 0건과 양수, 조회 중, 실패 후 재시도 결과를 확인한다.

## 검증

- 홈 위젯 테스트에서 요청 수 0건과 재시도 결과가 0건인 경우 버튼과 접근성 항목이 사라지는 것을 확인했다.
- 요청 조회 중, 조회 오류와 재시도, 양수 버튼 표시 및 이동을 기존 테스트로 확인했다.
- FVM 포맷과 분석, Flutter 테스트 900개, `git diff --check`가 통과했다.

## 요청 버튼을 숨길 때 제목 행 높이 유지

요청이 0건일 때 My place 제목 행이 줄어들어 아래 콘텐츠가 위로 움직인다. 제목 행에 요청 버튼과 같은 최소 높이를 적용한다.

- 요청이 있거나 0건일 때 My place 제목, 장소 콘텐츠, My plant 제목과 식물 콘텐츠의 세로 위치가 일치해야 한다.
- 회귀 위젯 테스트와 홈 캡처 세 장에서 위치를 확인한다.
