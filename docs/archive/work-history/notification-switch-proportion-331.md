# 알림 스위치 비율 수정 #331

설정 화면의 알림 스위치에 고정 상자, 가로·세로 채우기, 추가 축소가 겹쳐 위젯이 납작해 보인다.

1. 고정 상자와 가로·세로 채우기를 제거하고 화면에는 균일한 배율을 적용한다. 기본 터치 영역은 유지한다. 기존 색상과 켜기·끄기 동작은 유지한다.
2. 동일한 휴대전화 화면 크기에서 수정 전후 스위치의 실제 표시 영역과 이미지를 비교한다. 설정 흐름 테스트에서 토글 동작을 확인한다.
3. FVM 포맷·정적 분석·전체 테스트 및 diff 검사를 실행한다.

## 검증

- `1774622`에서 표시 비율과 터치 영역을 수정했다. 375×812 화면을 같은 앱 테마로 렌더링해 수정 전후 손잡이를 비교했다. 수정 전 스위치 위젯은 화면에서 31.2×18.7로 찌그러졌다. 수정 후에는 가로·세로 표시 배율이 같고 터치 영역이 60×48을 유지한다. 표시 영역 위쪽 바깥의 터치로 켜기·끄기도 확인했다.
- FVM 포맷 361개 파일, 정적 분석, 전체 테스트 883개 통과와 기존 골든 1개 건너뜀, diff 검사를 확인했다.
