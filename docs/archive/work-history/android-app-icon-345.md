# 안드로이드 앱 아이콘 #345

첨부한 3174×3174 PNG의 검은색 집·새싹 로고를 사용해 안드로이드의 해상도별 런처 리소스를 교체한다. Play 스토어용으로 둥근 프레임과 그림자를 제외한 흰 정사각형 배경의 512×512 PNG를 준비한다.

Android 빌드에서 패키징한 리소스와 에뮬레이터 런처를 확인한다. 스토어용 파일의 해상도, PNG 색상 채널과 용량을 검증한다.

## 구현 및 검증

- `4d66fd2`에서 적용 범위를 기록했고 `9dc8648`에서 Android 런처 리소스 5개와 배포 가이드를 갱신했다.
- FVM 포맷과 분석, Flutter 테스트 900개, `git diff --check`가 통과했다. 기존 테스트 1개는 제외됐다.
- FVM Android debug APK 빌드와 패키징된 해상도별 아이콘을 확인했고, Android 에뮬레이터 앱 목록에서 검은색 로고를 확인했다.
- Play 스토어용 `google-play-app-icon.png`는 512×512, 8비트 RGBA, sRGB, 20,295바이트이며 SHA-256은 `bcf8eb3e0281c68419d67e8d98f9aadaa5c25de87b416608ed538e6870eac094`이다.
