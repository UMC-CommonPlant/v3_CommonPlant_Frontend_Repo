# 회원가입 연령 확인 #339

회원가입 프로필에서 개인정보 이용 약관 위에 `만 14세 이상입니다.` 체크 항목을 추가한다. 기존 체크박스 스타일에 맞추고 행을 눌러 선택하거나 해제한다.

연령을 확인해야 가입을 계속할 수 있다. 체크 상태는 가입 초안에 두고 약관 화면을 왕복할 때 보존한다. 새 가입 세션은 미선택으로 시작한다.

작은 화면과 키보드 상태에서 체크 항목과 완료 버튼에 접근할 수 있는지 확인한다. 연령 미확인 상태에서 가입 요청이 전송되지 않으며, 연령 확인과 약관 동의를 거쳐 가입이 완료되는지 검증한다.

## 구현 및 검증

- `b90293c`에서 요구사항과 검증 범위를 기록했고, `f98c96e`에서 체크 항목, 가입 제출 조건과 기존 흐름의 회귀 검증을 반영했다.
- FVM 포맷과 분석, `git diff --check`, Flutter 테스트 899개가 통과했다. 기존 테스트 1개는 제외됐다.
- Android 에뮬레이터의 API 비사용 미리보기에서 약관 위의 위치, 연령 선택과 해제에 따른 완료 버튼 상태, 약관 화면 왕복 후 선택 보존을 확인했다.

## 필수 동의 보완

- 연령 확인과 개인정보 이용 약관 동의를 모두 선택해야 가입 완료 버튼과 가입 요청이 허용된다.
- 약관 화면의 확인 버튼은 동의 선택 후 활성화되며 프로필로 돌아간다. 가입 요청은 프로필 완료 버튼에서 진행한다.
- 위젯 테스트와 가입 요청 테스트에서 한 항목만 선택한 경우와 약관 화면의 이전 URL에 접근한 경우를 확인했다.
