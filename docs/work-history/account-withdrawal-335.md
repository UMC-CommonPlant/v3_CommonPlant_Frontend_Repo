# 설정 회원탈퇴 화면 #335

[회원탈퇴 시안](https://www.figma.com/design/aczb7WXctn1R3YFjmkgtXf/Common-Plant?node-id=170-13129)의 전용 화면을 설정의 회원탈퇴 항목에서 연다.

- 회원탈퇴 유의사항을 확인하면 삭제 버튼을 활성화한다.
- 기존 `DELETE /users`와 인증 세션 정리를 재사용한다. 처리 중 중복 제출을 막고 실패 시 같은 화면에서 다시 시도할 수 있다.
- 현재 API에서 확인할 수 있는 계정 이용 종료를 안내한다.
- 기존 설정 로그아웃은 확인창을 유지한다.

설정 진입과 뒤로 가기, 버튼 상태, 실패 후 재시도, 성공 후 로그인 이동을 테스트한다. 375×812와 작은 화면의 레이아웃을 확인하고 에뮬레이터에서 시안과 비교한다.
