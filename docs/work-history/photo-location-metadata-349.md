# 업로드 사진 촬영 위치 제거 #349

| 단계 | 완료 조건 | 검증 |
| --- | --- | --- |
| 1. 공통 사진 선택 | JPG·PNG·WebP 업로드 사본에서 위치를 포함할 수 있는 EXIF·XMP·텍스트 메타데이터를 제거한다. 사진 방향과 이미지 데이터는 유지한다. | 형식별 위치 메타데이터를 넣은 합성 입력, 방향 유지, 잘못된 파일의 제출 방지 |
| 2. 도메인 전달 | 가입·프로필·장소·식물이 정제된 공통 이미지 사본으로 기존 방식의 multipart를 만든다. | 사진 선택·미리보기·제출 회귀, 포맷, 정적 분석, 전체 Flutter 테스트, git diff --check |

정제는 선택한 바이트에만 적용한다. 운영 서버에 이미 저장된 사진과 실기기 업로드 확인은 별도 검증 범위다.
