# 로컬 로그아웃 세션 정리 #348

| 단계 | 완료 조건 | 검증 |
| --- | --- | --- |
| 1. CommonPlant 저장소 | 로그아웃 표시를 영속적으로 기록한 후 기존 access·refresh token을 삭제한다. 표시가 남은 상태에서는 앱 시작이 세션을 복원하지 않는다. | 저장소 오류와 새 앱 시작을 분리한 회귀 검증, 계정 변경·refresh-only 기존 테스트 |
| 2. 소셜 SDK | 카카오 SDK의 앱 토큰 저장소를 비우고 Google SDK 세션을 종료한다. Apple은 현재 저장하지 않는 Apple ID token 대신 공통 앱 세션을 종료한다. | SDK별 로컬 정리와 오류 격리 검증 |
| 3. 통합 | 로그아웃과 새 로그인이 정상 동작한다. | 포맷, 정적 분석, 전체 Flutter 테스트, git diff --check |

토큰 값과 계정 정보는 로그에 남기지 않는다. 실제 기기의 저장소 오류와 소셜 계정 전환 QA는 별도로 확인한다.
