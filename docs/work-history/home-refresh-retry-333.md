# 홈 새로고침과 목록 재시도 #333

홈에서 장소와 식물의 조회 결과를 각각 표시한다. 한쪽이 실패해도 불러온 목록과 받은 요청 수를 볼 수 있고, 실패 영역에서 직접 복구한다.

1. 기존 세 원격 조회를 함께 새로고침한다. 이미 조회 중인 항목은 진행 중인 요청을 기다린다. 짧은 홈 화면에서도 아래로 당길 수 있게 한다.
2. 목록별 loading, error, empty, success를 표시한다. 재시도는 실패 영역의 Provider만 다시 요청한다. 계정별 데이터 격리와 API 비사용 모드의 데이터를 보존한다.
3. 부분 실패·개별 재시도·당겨서 갱신의 화면 테스트와 FVM 포맷·정적 분석·전체 테스트 및 diff 검사를 완료한다.
